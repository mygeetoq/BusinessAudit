# CSV для личной загрузки

Эти файлы принимает форма «Данные → Загрузите операции из CSV». Номер счёта вводить не нужно: данные попадут в профиль вошедшего пользователя. Даты в файлах пересчитываются при каждом `go run ./scripts/gendemo`, поэтому сценарии остаются актуальными.

| Файл | Сценарий |
|---|---|
| `coffee_decline.csv` | 83 дня кофейни, плавный спад выручки и среднего чека |
| `coffee_crisis.csv` | Последующие 7 дней резкого падения; загружать после `coffee_decline.csv` |
| `bakery_growth.csv` | 120 дней устойчивой пекарни с ростом |
| `barbershop_decline.csv` | 90 дней барбершопа, спад в последнюю неделю |
| `foodtruck_growth.csv` | 60 дней растущего фудтрака |

Для сравнения независимых сценариев используйте разные профили. Повторная загрузка того же файла в одном профиле отклоняется. Эти CSV содержат только поступления и возвраты; для демонстрации кассового разрыва добавьте расходы в интерфейсе или выполните `make demo` / `make demo-extra`, которые загружают расходы и данные всех демонстрационных профилей через административный импорт.

В корне `data/` остаются исходные CSV старого демонстрационного сценария: `participants.csv`, `transactions.csv`, `transactions_crisis.csv`, `transactions_extra.csv`. В них есть колонка `account_id`, поэтому они предназначены для административного импорта, а не для личной формы.
